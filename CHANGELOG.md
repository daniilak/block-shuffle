# Changelog

## 1.3.6

- на масштабе `biome` отдельные куски одного биома получают разные блоки: все равнины мира больше не становятся одним материалом.

## 1.3.5

- запись в палитру секции идёт без замка: тик сервера и так один;
- за тик обрабатывается пачка чанков, но не дольше примерно 10 мс, чтобы игра не замирала.

## 1.3.4

- замена больше не вызывает `onPlace`/`onRemove` и проверку света на каждом блоке;
- карты высоты пересчитываются один раз на чанк;
- свет пересчитывается только у чанков, которые кто-то видит. Остальные досчитаются при загрузке.

## 1.3.3

- замена пишет блоки прямо в секцию чанка и отправляет игрокам один пакет на чанк вместо пакета на каждый блок;
- биом читается один раз на участок 4×4×4, а не на каждый блок;
- очереди чанков разделены по измерениям, чтобы проход по Верхнему миру не перебирал очередь Нижнего мира.

## 1.3.2

- новый масштаб `/blockshuffle scale biome`: один биом — один случайный блок, граница замены совпадает с границей биома;
- одинаковый биом в одном измерении получает один и тот же блок, пещерные биомы считаются отдельно.

## 1.3.1

- `/blockshuffle pregen` только прогружает чанки и не меняет блоки;
- `/blockshuffle all` заменяет все уже сгенерированные чанки выбранных миров, включая ранее обработанные;
- масштаб берётся из текущего мира и применяется к выбранным измерениям.

## 1.3.0

- замена больше не запускается сама при создании мира;
- старт только командой: `/blockshuffle` или `/blockshuffle all` включает все миры;
- `/blockshuffle overworld` — только Верхний мир;
- `/blockshuffle both` — Нижний и Верхний миры;
- `/blockshuffle nether` — только Нижний мир;
- повторный выбор выключает авторандом в мирах, которых нет в команде.

## 1.2.1

- устранён вылет при выпадении резной тыквы или светильника Джека: ванильная проверка создания голема могла обратиться к ещё не загруженному блоку;
- черепа визер-скелета также исключены как блоки с автоматической проверкой многоблочной конструкции;
- добавлен runtime-карантин: несовместимый блок другого мода заменяется камнем и исключается из дальнейшей обработки вместо остановки сервера;
- отложенные данные исходных контейнеров корректно загружаются и очищаются перед заменой блока;
- ульи, верстаки, контейнеры и остальные безопасные блоки сохранены в полном пуле;
- очередь ограничена одним чанком за тик, что уменьшает зависания серверного потока.

## 1.2.0

- полный пул всех зарегистрированных блоков с предметной формой;
- верстаки, ульи, контейнеры, рабочие блоки, песок и блоки сложной формы участвуют в замене;
- блоки модов автоматически попадают в пул при наличии нормальной предметной формы;
- Верхний мир, Ад и Энд получают независимую раскладку;
- исправлен конфликт очередей одинаковых координат между измерениями;
- чанк помечается обработанным только после успешной замены;
- добавлена диагностическая команда `/blockshuffle pool`;
- управляющие команды ограничены OP-уровнем 2;
- блоки-сущности сделаны редкими для защиты производительности.

## 1.1.0

- публичное название Block Shuffle;
- новый mod ID `blockshuffle`;
- команды и ресурсы переведены на новое имя;
- подготовка проекта к GitHub Actions и публикации.
